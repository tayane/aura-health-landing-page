# 🩺 Aura Health — Medical & Wellness Landing Page

A modern, clean, and high-converting landing page built for **Aura Health & Medical Center**, a fictional integrated medicine clinic.

Designed specifically to demonstrate expertise in medical services marketing, strong value propositions, mobile-first responsiveness, and conversion-focused UI design.

## ✨ Key Features

- **Proactive Value Proposition**: Highlighting medical prevention, personalized diagnostics, and longevity care.
- **Service Breakdown**: Structured grid showcasing clinical specialties with clean Lucide icons.
- **Key Differentiators**: Visual highlights emphasizing zero wait times, 60-minute consultations, and multidisciplinary care.
- **Identified Demonstrative Reviews**: Customer social proof clearly labeled for portfolio demonstration compliance.
- **Interactive Appointment Form**: Functional frontend form simulation with validation and success state feedback.
- **Mobile-First & Accessible**: Fully responsive navigation and layout optimized across all screen sizes.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic markup optimized for accessibility.
- **CSS3**: Modern Flexbox, CSS Grid, smooth transitions, and custom CSS variables.
- **JavaScript (ES6+)**: DOM manipulation for mobile navigation and form handling.
- **Lucide Icons**: Feather-based lightweight icons.
